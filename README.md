# EMSTRUE COLLECTION Landing Page

## Project Overview

EMSTRUE COLLECTION is a polished single-page landing page for a luxury ladies' fashion accessories business.

The website presents curated handbags, jewellery and shoes while giving visitors a simple way to explore the collection and contact the business.

## Capstone Requirements Covered

- Hero section
- Business introduction
- Primary call-to-action
- Collections
- Featured products / recent work
- Three core services
- How We Work section
- Contact form
- Footer with navigation and social links
- Responsive design
- JavaScript interactions
- Accessibility considerations
- Social media links
- Business disclaimer

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Website Sections

1. Home / Hero
2. Our Collections
3. Featured Collection
4. Services
5. How We Work
6. Contact
7. Footer

## JavaScript Interactions

JavaScript is used for:

- Contact form validation and feedback
- Header quick-action navigation
- Product search interaction
- Favourite button feedback
- Cart button feedback
- Profile button feedback

The contact form is a frontend demonstration. It does not send information to a real backend or email service.

## Responsive Design

The website includes responsive CSS for:

- Desktop
- Tablet
- Mobile

The layout should be tested around 1366px desktop width and 375px mobile width.

## Accessibility

The project includes:

- Semantic HTML5 sections
- Descriptive image alt text
- Form labels
- Accessible button labels
- Logical heading hierarchy
- Keyboard focus states
- Reduced-motion support
